Enter 2245820 in Downloader by AFTVnews. This code provides the app download; it does not activate a trial or subscription.
Check These Three Things First
Your device is connected to the internet and has space for an app.
You have installed Downloader by AFTVnews from the available official app store.
You have requested your trial or subscription username and password from our team.
The supplied APK is for compatible Firestick and Android-based devices. A television or device running another operating system may need a different player.
Install the Sky Glass App on Firestick
On the Firestick home screen, search for Downloader by AFTVnews and install it from the Amazon Appstore.
Open Settings → My Fire TV → Developer Options → Install Unknown Apps and allow Downloader to install apps. Fire OS menu names can differ by version.
If Developer Options is hidden, open Settings → My Fire TV → About, select the device name repeatedly until the developer message appears, then return to the previous menu.
Open Downloader, enter 2245820 in its code or URL field and select Go.
Review the download prompt. Install the supplied Sky Glass App and open it.
Sign in with the username and password our team sent you.
Install the Sky Glass App on an Android-Based Device
On a compatible Android TV, Google TV, Android box, phone or tablet, install Downloader by AFTVnews from the available official app store.
If your device asks, allow Downloader to install apps from this source. Setting names differ between manufacturers.
Open Downloader, enter 2245820 and select Go.
Review the download prompt, install the supplied app and open it.
Enter your supplied username and password.
If your device cannot install the APK, tell support its exact model and Android version.
Sign In to Your Account
The app supplied through Skyglass-iptv.com asks for a username and password. Enter both exactly as sent, without extra spaces. You do not need to type a separate server address in this supplied app.
Installing the app alone does not give you an active account. If you use another compatible IPTV player, its login screen may ask for a server URL or other details. Request the information needed by that player from support. 2245820 is a download code, not a login code.
Once your active Premium account loads, the advertised package contains 27,000+ live channel entries and 120,000+ on-demand film and series entries. Individual entries can change, and the trial catalogue may differ from paid access.
Using a Different Type of Device?
A supported Samsung or LG television without Android TV, an Apple device or a computer needs a compatible player designed for its operating system. The APK steps above do not apply directly. Send support the exact model so they can advise you on the appropriate player and account details.
If Something Stops Working
Downloader does not open the code: Check the internet connection and re-enter 2245820.
Installation is blocked: Check whether Downloader has permission to install apps.
The app will not install: Check available storage and tell support the device model and system version.
Your login is rejected: Remove extra spaces and ask support to confirm your account status.
The app opens but categories do not load: Restart it and confirm that your trial or subscription is active.
Playback stops after using a second screen: Check whether your account allows more than one simultaneous stream.
If you still need help, send support the device model, app name, exact error and the step where it happened. Hide your password in screenshots.
